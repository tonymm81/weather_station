Tää laitos toimii siten että rasbeperry pi 3 toimii brokserina ja sää asemana ja myös näyttönä. Lähpötiloja ja kosteuksia ja luxeja mittailee 3 kpl esp32 microklontrolleria.

Esp32 mikrokontrollerit ovat siis clientejä, jotaka lähettää mitta tulokset mqtt viesteille brokerille.

Sitten tekniikasta. Kun sää asema käynnistetään, se käynnistää siis ensin weatherstation.py tiedoston joka käynnistää connentions.py jossa mqtt koodi. COnnections.py sen sijaan kutsuu shutdown.py tiedostoa joka taas komentaa sähköt noihin (broadlink kirjasto) esp32 microkontrollereihin, eli käynnistys järjesteys pitäisi olla oikein. Ensin broker tulille ja sitten vasta clientit.

Tämän jälkeen ohjelma siis odottelee mqtt viestejä ja tunnin välein tallentaa kantaan mitta tulokset ja myös ohjelman näytölle. Miläki weatherstation.py huomaa, että jokin esp32 on mennyt aikaleiman perusteella offlineen, se koittaa resetoida shutdown.py kautta.


Ongelma. 
Joskus kun ohjelman käynnistää nollasta, se resetoi loputtomiin yhtä microkontrolleria kunnes tilttaa. Joskus olen saanut ongelman pois että resetoin esp32 käsin mutta sekään ei aina auta. Se joskus auttaa että brokerin vaan buuttaa mutta joskus se ongelma toistuu silti.

Ympäristö missä mikrokontrollerit ovat, kattaa koko wlan verkko tämän alueen ja jännintä on se että tuo ohjelma koittaa aina resetoida tuota lähimpänä modeemia olevaa esp32. Eli nyt pitäisi lähtee debuggaamaa, miksi tämä ei toimi.

Uita voisi parantaa siten, että lämpötilat ja kosteudet näkyisi paremmin näytöllä koska se on vain 7 tuumainen näyttö täynnä tekstiä tällä hetkellä.

Resetointi pitää tsekata ettei siinä oo ajatusvirheitä. Myös antureiden antamat luxiarvojen laskut täytyisi toteuttaa jotenkin koska nyt ne näyttöö 0-4095.

class ComponentFormatter(logging.Formatter):
    def format(self, record):
        if not hasattr(record, "component"):
            record.component = record.name  
        return super().format(record)

def make_logger(name, path, level=logging.INFO):
    logger = logging.getLogger(name)
    logger.setLevel(level)

    if not logger.handlers:
        handler = RotatingFileHandler(path, maxBytes=5*1024*1024, backupCount=5)

        fmt = '%(asctime)s %(levelname)s %(name)s %(component)s: %(message)s'
        formatter = ComponentFormatter(fmt)

        handler.setFormatter(formatter)
        logger.addHandler(handler)

    return logger
